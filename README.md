# TryHackMe Labs & Cybersecurity Documentation

Welcome to my cybersecurity lab notebook. This repository serves as a centralized, enterprise-grade log of my hands-on technical training, simulated network defense exercises, and specialized learning pathways completed on TryHackMe. 

The purpose of this repository is to bridge theoretical computer science concepts with practical, real-world defensive operations. Each module entry demonstrates active problem-solving, analytical thinking, and the documentation skills required of a modern security professional.

---

## 🛠️ Core Skills & Technical Proficiencies

Through rigorous, hands-on lab environments, I actively practice and document proficiency in the following security domains:

### 🔍 Reconnaissance & Vulnerability Assessment
* **Directory Enumeration:** Utilizing automated scanning tools like **Gobuster** to perform brute-force URI discovery, identifying hidden directories, exposed files, and unlinked web assets.
* **Attack Surface Mapping:** Analyzing how malicious actors leverage open-source intelligence (OSINT) and active scanning to find misconfigurations before attempting exploitation.

### 🛡️ Defensive Security & Risk Mitigation
* **Security Controls:** Applying the core principles of Administrative, Technical, and Physical security controls to protect enterprise assets.
* **Access Control & Hardening:** Documenting best practices for removing sensitive hidden directories, restricting unauthorized access, and minimizing system attack surfaces.
* **Monitoring & Visibility:** Analyzing log files and scanning activity to detect suspicious network patterns and potential web application exploitation.

### 🐧 Systems & Infrastructure Administration
* **Operating Systems:** Fluent navigation of the **Linux Terminal** command-line interface to interact with systems, execute tools, and manage data.
* **Web Architecture:** Understanding client-server communication models, browser-based data transfers, and web application configurations.

## 📋 Documentation Standards

Every lab and room documented in this repository follows a strict enterprise reporting structure:
1. **Executive Summary:** Defining the pathway objectives and business impact.
2. **Core Concepts:** Breaking down the underlying security methodologies.
3. **Lab Activities & Tool Analysis:** Detailing the exact commands, syntax, and tools used to complete the mission.
4. **Defensive Takeaways:** Translating the offensive scenario into actionable defensive recommendations.
